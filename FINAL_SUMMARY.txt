LOCAL DEVELOPMENT:
  1. Navigate to project directory
  2. Run: pnpm install (or npm install)
  3. Run: pnpm dev (or npm run dev)
  4. Open: http://localhost:3000

CHATBOT ACCESS:
  - Main chat: http://localhost:3000
  - Admin control room: http://localhost:3000/admin
  - Admin password: admin123

MOBILE/PWA INSTALLATION:
  1. Open app in Android browser
  2. Look for "Install Support Bot" button
  3. Click "Install"
  4. App installs to home screen
  5. Works offline with cached data

DEPLOYMENT TO VERCEL:
  1. Connect GitHub repository
  2. Click "Publish" button (v0 UI)
  3. App deployed automatically
  4. Accessible at https://your-app.vercel.app

DOWNLOAD ZIP:
  1. Click three dots (top right)
  2. Select "Download ZIP"
  3. Extract and use locally
